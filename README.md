# sort-algo-rs

Sorting algorithm implementations in pure Rust.

## Algorithms

- **Quicksort** (Lomuto & Hoare partition schemes)
- **Mergesort** (stable, out-of-place merge)
- **Heapsort** (max-heap based)
- **Timsort-inspired** (adaptive merge sort with run detection)
- **Counting Sort** (non-comparative, stable)
- **Radix Sort** (LSD radix sort, base-256)
